# Mihiretu Yeshi Portfolio

Personal portfolio built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build and verify

```sh
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel and deploy it. The included `vercel.json`
configures Vercel to run `npm run build`, publish the `dist` directory, and
serve the app for client-side routes. Vercel can use the npm lockfile to install
the project dependencies.
